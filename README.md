# 🤖 Jarvis AI Assistant

Jarvis is a Python-based AI voice assistant that allows users to interact with a computer using voice commands.

## 🚀 Features

- 🎙️ Voice-based interaction
- 🧠 AI-powered responses using an LLM
- 🌐 Open Google, YouTube, Facebook and LinkedIn
- 🎵 Play songs through voice commands
- 📰 Get the latest Indian news
- 🔊 Text-to-speech responses
- 💻 Local AI processing using Ollama

## 💡 Problem Statement

Traditional computer interactions require users to manually open applications, search for information, and perform repetitive tasks.

Jarvis provides a voice-based interface that allows users to perform common tasks and get AI-powered answers through natural language commands.

## 🛠️ Technologies Used

- Python
- SpeechRecognition
- PyAudio
- Ollama
- LLM
- Requests
- Text-to-Speech
- NewsAPI

## ⚙️ How It Works

1. User gives a voice command.
2. Jarvis converts speech into text.
3. The command is processed.
4. Jarvis either performs the requested task or sends the question to the local AI model.
5. Jarvis converts the response into speech.
